# 完成标准

本仓库中的“100%”表示：声明的发布范围内每项检查都有可复现证据。它不表示 LLM 系统在未知仓库上永远不会失败。

## 核心 Agent v0.1 范围

满足以下条件时，v0.1 核心能力才算完成：

- 所有离线测试通过；
- 11 个模型回归案例全部满足详细条件；
- 分析、创建、修改、仅验证、负面测试、澄清、恢复、短提示、范围隔离和记忆路径均有覆盖；
- 必需行为连接到已执行证据；
- 只读和受保护文件任务报告 0 个未经授权的源码变更；
- 修复循环、重复读取和模型动作重试均有界；
- 核心运行时中不存在基准、夹具、模型提供商或业务领域专用规则。

v0.1 支持边界是 Python/pytest 加基础的直接 POSIX Shell 执行。JavaScript、Go、Rust、持久化 LangGraph 存储和操作系统级沙箱属于路线图，不是隐含能力声明。

## 本地候选发布范围

本地 `v0.1.0-alpha` 候选版本满足以下条件才算完成：

- 通过 `python scripts/release_check.py` 完成源码扫描、编译、pytest、wheel/sdist 构建、包内容检查、干净 wheel 冒烟测试以及所有控制台 `--help` 检查；
- 规范的 11 案例审计包通过 `python scripts/collect_regression_audits.py --strict`；
- 本地模型配置、凭证、运行状态和审计归档均被忽略；
- 发布、安全、贡献、架构、验证、演示和限制文档齐全。

公开发布还要求选择仓库 URL、在精确提交上运行公开 CI、扫描最终 Git 历史、创建标签并发布 Release。这些账户相关操作已于 2026-07-23 为 `v0.1.0-alpha` 完成。

## v0.2 真实世界证据范围

下一个证据里程碑满足以下条件才算完成：

- 至少公开 10 个具有可复现来源和外部隐藏验收的真实仓库案例；
- 集合包含多文件修复、含糊 Issue、依赖/API 迁移和更大的保留测试套件；
- 外部解决结果与 Agent 最终声明分开报告；
- 报告成功声明精确率、假阳性、假阴性、变更文件范围、耗时、模型调用和 Token；
- 每个由评测失败推动的运行时变更都代表一类通用失败，并拥有离线回归测试。

## 作品集范围

当评审者能够做到以下事项时，项目才算达到作品集完成标准：

- 五分钟内通过 README 理解问题和架构；
- 复现离线发布门禁和模型回归矩阵；
- 检查诚实记录的指标、失败、修复与限制；
- 在不需要私有配置的情况下跟随简短演示；
- 阅读技术深度解析和面试指南；
- 复用简历要点和口头项目介绍。
