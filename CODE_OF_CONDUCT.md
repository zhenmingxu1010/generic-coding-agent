# Code of Conduct

## Our standards

We are committed to a respectful, harassment-free community. Examples of
positive behavior include constructive feedback, empathy, clear technical
discussion, and respect for different backgrounds and experience levels.

Unacceptable behavior includes harassment, personal attacks, discriminatory
language, deliberate intimidation, publishing another person's private
information, or disrupting project discussions.

## Enforcement

Project maintainers may edit or remove comments, commits, code, issues, and
other contributions that violate these standards. They may temporarily or
permanently restrict participation when necessary.

Report conduct concerns privately to the project maintainer using the contact
channel shown on the maintainer's GitHub profile. Reports will be reviewed as
promptly and confidentially as practical.
